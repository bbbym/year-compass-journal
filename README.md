# Year Compass

A calm, responsive personal planning dashboard designed for desktop Safari and iPad.

Includes two editorial image-backed card themes inspired by the supplied red/black and blue/silver references, alongside the original calm palettes.

## Run locally

Open `index.html` directly, or serve the directory with any static web server.

## Data and privacy

Tasks, records and appearance settings are stored with browser `localStorage`. They remain available in the same Safari profile after refreshing or reopening the site. Safari Private Browsing and clearing website data will remove those records. Data is not synced between devices.

## Deployment

The production build is the `dist/` directory. The project can be hosted as a static site on Cloudflare's runtime with no build command.
